# 评估：a 评判 options 的字段、回填与校准

适用：评估表用于 a 在 `options.md` 的候选之间取舍时（含 asd 循环），符合 `roles.md` 小改动阈值的改动不需要评估表；「回应 c 的意见」「回填与校准」两节对任何场合的 c 意见与已实施的方向都适用。a 评判方向、回应 c 的意见、回填结果时读本文件。字段由本文件写死，a 不临场增减。阈值的默认值与本项目的值见项目 `outline.md` 的「判据与阈值」一节；没有 `personas/` 的项目，由 a 在回复里写出所用的阈值，回复里的评估表同样要有 O0 一行。分数一律附依据；对没有「达标」的档（见「回填与校准」），数只用来排序和对照事先写定的阈值。

## 字段（写在 `options.md` 的评估列，谁写见右栏）

| 字段 | 含义与端点 | 谁写 |
|---|---|---|
| 可行性 f（0–1） | 在期限内达成判据的可能。1 = 完全可以达成，0 = 完全达不成 | a |
| 重要性 i（0–1） | 达成时对判据的贡献。1 = 完全达成目标，0 = 与目标无关 | a |
| t | 用真实环境验证它成不成立，最少要几天（写数字） | s 先写，a 可改 |
| 可撤回 | 是／否；是 = 能在 N 天内恢复到决定之前的状态（N 见阈值表） | a |
| 成本 | 写数和单位（天数、提交次数、配额、金额）；每种单位在阈值表里各有一个上限 C | a |
| 影响面 | 会看到这次结果的使用者数，或计入评估的结果笔数；写数和单位（使用者／结果笔数） | a |
| 实际结果 | 回填：达成判据写 1，未达成写 0（判据是数字时按阈值，是／否问句时按它的通过条件）；没有实施的方向写「—」 | a |
| 实际贡献 | 回填：判据是数字时，(实测值 − 基线) ÷ (目标值 − 基线)，截到 0–1；基线与目标值事先写在判据里。分母为 0、判据不是数字、或目标是维持现状时写「—」 | a |

- 依据沿用 `options.md` 的「依据」栏（`data_collected.md` 的条目号，或「无来源」）；依据栏写「无来源」的方向，f、i 不得高于 0.5（上限见阈值表）。
- 优先 = f × i，只用于排序，不当概率。
- 每次评估，`options.md` 里必须有「维持现状」一行（编号 O0），评估列与其他方向相同；缺这一行，本次评估无效。O0 的「a 的判定」「实际结果」「实际贡献」三列都写「—」，不归档，每次评估前 a 按当前目标重写它的其余评估列。
- 否决 = 「a 的判定」为「未通过」或「变招中」；搁置 = 「a 的判定」为「待判」且「理由」以「搁置：」起头（本次不做，也没有否决）。被否决或被搁置的方向，t 必须填。
- 「未评估」只用于旧条目的 f、i、t、可撤回、成本、影响面列；实际结果列在没有实施时写「—」，实际贡献列在没有实施或判据不是数字时写「—」。

## 场地与代理指标

- 用某个场地的读数核准或否决一个方向之前，a 在该方向的「理由」里写出：样本数 n（个数，单独写）；噪声底 σ、目标效应 e、可检出的最小差 δ，三者用同一个单位（判据的单位）、都取非负值（e、δ 是差值的大小），并各写估计方法或来源（重复测量、历史数据、公式）。e < δ 的场地只能当安全闸门（会不会坏），不得当优劣依据；安全闸门与优劣闸门分开写。
- 场地与真实场景的相似度（0–1；1 = 与真实场景相同，0 = 毫无关系）加依据，只在 e ≥ δ 的场地之间排序。
- 每个代理指标登记在 `outline.md`「判据与阈值」的代理指标登记表里：单位与转换方式（代理值与真实值同尺度才比较）、最近一次对照（代理值、真实值、日期）、该指标自己的 τ。差的绝对值大于 τ 时状态记「降级」，降级的指标既不能核准也不能否决；新对照的差不大于 τ 才能恢复；τ 用转换后的尺度。τ 没写的代理指标，不得用于核准或否决。
- 消融或拆解单的触发条件：对应方向已有至少一次真实场地读数（写读数编号）；没有读数就不派，除非该方向的安全闸门失败。

## 流程轻重

每个要决定做不做的事项（`options.md` 里的方向，含 O0）写可撤回、成本、影响面。可撤回为「是」，成本的每一项都不超过同单位的 C，且影响面的每一项都不超过同单位的 W，走轻流程：只过安全闸门，并事先写下一句撤回条件（读到某个数就撤回）；否则走完整流程，送 c。成本或影响面的单位在阈值表里没有 C 或 W 的，按走完整流程处理。N、C、W 见阈值表。

## 回应 c 的意见

a 回应 c 的清单，每条写严重度「严」和相关性「相」（各 0–1，各附一句依据）：严：1 = 不处理则结论完全错误，0 = 对结论无影响；相：1 = 就是主线，0 = 与主线无关。优先 = 严 × 相：不小于 θ1 的必处理；不小于 θ2 且小于 θ1 的顺手处理；小于 θ2 的建议不修复。分数只决定修复和量测的先后，不免除回应：阻断和提问无论分数都逐条回应（采纳，或不采纳并写理由与分数依据）；建议逐条写采纳或不采纳及理由，其中优先小于 θ2 的建议不修复，仍逐条写不采纳、理由和分数依据；同类可以合并排版。不采纳的写出分数与依据。量测单按同一优先决定派不派。

## 回填与校准

- 每个方向结案时，a 回填「实际结果」与「实际贡献」；f 在开始实施前写定，回填时不改。有效行 = f 是 0–1 的数、在开始实施前已写定且之后没有改动、「实际结果」为 1 或 0 的行（写「—」的不计）；已归档的行也回填、也计入有效行，回填时可读它的 f，只改它的实际结果与实际贡献两列（f 不改），不读变招列。
- 每新增 K 条有效行，a 请 e 用只读脚本算一次，统计用全部有效行（累计），结果写在回复里：
  - 按 f 分三档：f < 1/3，1/3 ≤ f < 2/3，f ≥ 2/3；每档算实际达成率（档内「实际结果」的平均）和档内 f 的平均；
  - Brier 分数 = 每条有效行 (f − 实际结果) 的平方的平均；
  - 某档有效行不足 M 条的，该档不判定，写「数据不足」；
  - 某档「实际达成率 − 档内 f 的平均」的绝对值大于 D 的，在阈值表里记「f 在该档偏高」（达成率低于 f 的平均）或「偏低」，之后写 f 时参考；
  - 某档有效行不少于 M 条，且上述绝对值不大于 D 的，该档「达标」。
- 只有「达标」的档里的 f 可当概率用；其他档的 f、i 只当相对排序；下一次重算该档不再达标，就退回排序。
- 限制：只有实施过的方向有实际结果，被 a 否决而没有实施的方向没有，所以校准主要覆盖 f 较高的档；i 只有在判据是数字时才能校准。
- 脚本由使用者的项目提供或由 e 临时写，本包不附脚本。

## c 查验评估是否齐全

c 对被否决、被搁置（定义见「字段」一节）或「维持现状」的每个方向，列出 f、i、依据、t 是否齐全（齐全／缺哪项），缺项记「依据不齐」；依据齐全率 = 已填字段数 ÷ 应填字段数。这一栏 c 只列缺项，不回答替代方案，不改 a 的判定；c 对数字和依据本身是否站得住的审查不受此限。
