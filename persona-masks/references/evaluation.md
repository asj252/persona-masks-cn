# 评估动作入口

先读 [共用前提](evaluation-context.md)。重要方向取舍可用评估表，简单事项可文字说明；回应c不新增评估表。跨动作读齐；未指定动作的评估与 asd 保守读全部文件并读 ideate。

| 动作 | 完整读取 |
|---|---|
| a assess | context、fields、assess |
| a respond | context、respond |
| a backfill | context、fields、backfill |
| c check | context、fields、assess、check（只查完整性，不接管裁决） |

可重复 `--evaluation-action assess/respond/backfill/check`；参数不切角色、不写文件。文件名均为本目录 `evaluation-<名称>.md`。
